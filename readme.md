# 4. Wireframes a mano

Se realizarán bocetos en papel para definir la estructura y distribución de los elementos principales del sitio web.

Como mínimo se realizarán 10 secciones:

1. Inicio.
2. Nosotros.
3. Servicios.
4. Cámaras de seguridad.
5. Sistemas de alarmas.
6. Redes y conectividad.
7. Servicio técnico.
8. Sistemas contra incendio.
9. Preguntas frecuentes.
10. Contacto.
11. Solicitar presupuesto.
12. Proyectos realizados.

Los wireframes permitirán definir previamente la estructura de cada sección antes de realizar el diseño digital en Figma.

Los bocetos estarán orientados principalmente a determinar:

- Ubicación del menú.
- Encabezado.
- Imágenes y contenido.
- Botones.
- Tarjetas de servicios.
- Formularios.
- Secciones informativas.
- Pie de página.
- Navegación entre páginas.
